Sesi Refilwe's birthday page
============================

Open index.html in a browser to see it (an internet connection is needed for the fonts).

Files
  index.html   the whole page (text, styles, gift, music and wish)
  images/      her photos (p10.jpg is the big portrait at the top)

Change a photo: replace the file in images/ with another photo of the same name.
Change the words: open index.html in any text editor and edit the text.

To put it online: drag this whole folder onto https://app.netlify.com/drop
or upload it to GitHub Pages. Keep index.html and the images folder together.
